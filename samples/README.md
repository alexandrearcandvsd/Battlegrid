# Sample maps

These JSON maps are format **v2** Battlegrid files. Open one with **Import** in the editor, or copy the `seed` and `generatorProfile` to regenerate.

| File | Theater |
| --- | --- |
| `grasslands.json` | Temperate Grasslands |
| `urban-base.json` | Urban military base |
| `alpine.json` | Alpine Mountains |
| `coastal.json` | Coastal |
| `lunar.json` | Lunar |
| `martian.json` | Martian |

These six files cover the core Inner Sphere and off-world tables. Other theaters are on the **Biome** list in Generate.

Battlegrid is not a virtual tabletop. The files contain terrain, elevation, marks, and buildings only.
